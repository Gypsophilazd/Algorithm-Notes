## 题目描述

在 $N \times N$ 的棋盘里面放 $K$ 个国王，使他们互不攻击，共有多少种摆放方案。国王能攻击到它上下左右，以及左上左下右上右下八个方向上附近的各一个格子，共 $8$ 个格子。

## 输入格式

只有一行，包含两个数 $N,K$。

## 输出格式

所得的方案数

## 输入输出样例 #1

### 输入 #1

```
3 2

```

### 输出 #1

```
16

```

## 说明/提示

### 数据范围及约定

对于全部数据，$1 \le N \le 9$，$0 \le K \le N\times N$。

---

$\text{upd 2018.4.25}$：数据有加强。

## Solution

小国王。状压 DP 模版题。所谓状压 DP 的心法，即为“状态，永远只记录跨越边界的东西”。
本题亦是如此。考虑每个国王的位置信息，我们需要浓缩为三维，即状态定义为 $dp[i][j][a]$ 表示第 $i$ 行，放到第 $j$ 个国王，当前行状态为 $a$ 的方案数，第三维的构造是需要花费心力思考的，原因是本题的限制，即每行国王之间应当互不侵犯，这提示我们需要构造 $a$ 状态。状态压缩即当前 $a$ 状态下，每一位中的 $1$ 表示该列放置国王，$0$ 表示不放置。

状压 DP 的状态转移方程通常简明，都是当前状态累加上一个位置信息的所有合法状态数。即：$$dp[i][j][a] = \sum{dp[i-1][j-c[i]][b]}$$
其中 `c[i]` 表示当前第 $i$ 行放的国王数量。

状态转移方程提出后，状压 DP 的下一个难题是判定状态转移的边界。显然第一个限制是，本行内的国王不应该有互相攻击的情况，即两个 $1$ 不应该相邻。这里提供一个用于判断两数$i,j$ 每位之间存在何种关系的心法，即枚举 $i$ 从 $[0,(1<<n))$，表示 $i$ 的可能范围，枚举 $j$ 从 $[0,n)$ 表示一共有 $j$ 位。那么，在本题的情况下，判断数 $i$ 是否存在相邻位的 $1$ 的判断代码应当是 `i & (i >> 1) != 0;` 可以预处理到合法状态 `st[1 << N]` 数组中，便于剪枝。

如何统计某数中二进制位 $1$ 的个数？可以考虑内置函数`__builtin_popcount()`，也可以开一个二重循环来统计。

枚举状态进行转移时，判断状态 $a$ 与状态 $b$ 之间是否可以转移，其判断条件应当是
```cpp
(a & b != 1) && (a & (b >> 1) != 1) && (a & (b << 1) != 1)
```
即满足周围 $8$ 格均不存在国王。
初始化 `dp[0][0] = 1`，表示不放也是一种方案，枚举到最后一行，答案即为`dp[n + 1][k][0]`。

## Code

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;
const int N = 12;
int n, k, cnt;
int dp[N][N * N][1 << N];
int s[1 << N], num[1 << N];

signed main(){
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    cin >> n >> k;
    for(int i = 0; i < (1 << n); ++i){
        if(!(i & (i >> 1))){
            s[cnt++] = i;
            num[i] = __builtin_popcount(i);
        }
    }
    dp[0][0][0] = 1;
    for(int i = 1; i <= n + 1; ++i){
        for(int j = 0; j <= k; ++j){
            for(int a = 0; a < cnt; ++a){
                for(int b = 0; b < cnt; ++b){
                    int c = num[s[a]];
                    if((j >= c) && !(s[b] & s[a]) && !(s[b] & s[a] >> 1) && !(s[b] & s[a] << 1)){
                        dp[i][j][a] += dp[i - 1][j - c][b];
                    }
                }
            }
        }
    }
    cout << dp[n + 1][k][0];
    return 0;
}

```
