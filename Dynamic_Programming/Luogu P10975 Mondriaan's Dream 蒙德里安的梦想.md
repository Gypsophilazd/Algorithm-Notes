## 题目描述

荷兰著名画家皮特·蒙德里安对正方形和矩形非常着迷。有一天晚上，在创作完他的“厕所系列”画作后（他不得不用厕纸画画，因为他所有的画纸都用完了），他梦见用宽度为 $2$、高度为 $1$ 的小矩形以不同的方式填充一个大矩形。

![](Note/ACM%E8%AE%AD%E7%BB%83/Dynamic_Programming/images/8e4fea57383b172c654b6486f8d083ba_MD5.webp)

作为这方面的专家，他一眼就看出需要使用计算机来计算填充这个大矩形的不同方式。请帮助他，以免他的梦想变成噩梦！

## 输入格式

输入包含多个测试用例。每个测试用例由两个整数构成：大矩形的高度 $h$ 和宽度 $w$。当 $h = w = 0$ 时输入结束。否则，$1 \leq h, w \leq 11$。

## 输出格式

对于每个测试用例，输出使用大小为 $2\times 1$ 的小矩形填充给定大矩形的不同方式的数量。假设给定的大矩形是定向的，即对称的铺砌方式应多次计算。

## Code

本题一个最 tricky 的点就是：横放的方案数 = 总方案数。

为什么横放决定一切，而竖放不行？

假设规定了所有的竖放骨牌的位置。剩下的空位，打算全用横放骨牌填满。

我们会发现一个致命问题：**一段连续的、形如 $2 \times 2$ 的空白正方形，既可以放两个横着的，也可以放两个竖着的！**

如果你只固定竖放，剩下的空间可能会产生多种横放填法。这就导致“竖放方案数 $\neq$ 总方案数”。但是如果固定了所有的**横放**骨牌，剩下的空白区域被切割成了若干个宽度只有 1 的垂直长条！在宽度为 1 的长条里塞 $1 \times 2$ 的竖骨牌，**只有唯一的一种塞法**（要么正好塞满，要么塞不满直接非法）。

于是我们有状态定义 $dp[i][j]$ 表示第 $i$ 列，状态为 $j$ 的方案数。

那么先推导状态转移方程，很确定，即：$$dp[i][j] = \sum{dp[i-1][k]}$$
其中 $k$ 表示所有的上一列的合法状态。

于是我们又需要考虑合法状态 $k$ 的定义与其边界。状态压缩，设状态 $k$ 的每二进制位表示骨牌不同的状态。第 $j$ 个二进制位为 $1$ 表示该列的第 $j$ 行骨牌横放。为 $0$ 表示该位置骨牌竖放。观察 $j, k$ 的关系，其思维链如下：

若 $j = 1001$ 那么必然有 $k = 0xx0$，其中 $x = 0/1$。那么考虑逐位比较，得到了本题的第一个限制条件，即`j & k = 0`。

不过如果这样还是棋差一着，因为 $0$ 表示竖放骨牌，也就是说，每列的位置不可连续出现奇数个 $0$，我们需要预处理 `st[1 << N]` 表示合法列的状态。排除所有出现奇数 $0$ 的状态。
此外，还需要注意的是，在判断状态 $j, k$ 是否能兼容时，如果只算 `st[j]`，等于忽略了上一列凸出来的半截骨牌。 实际上，第 $i$ 列被占据的总格子，是 `j` 和 `k` 的**叠加**，也就是按位或：**`j | k`**。 只有把 `j | k` 合并起来，剩下的那些 0，才是第 $i$ 列真正干干净净、可以用来插竖骨牌的连续空位。

有了如上的分析，就可以写出精炼的结果。

## Code

```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;
const int N = 13;
int dp[N][1 << N];
bool st[1 << N];

signed main(){
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int n, m;
    while(cin >> n >> m){
        if(n == 0 && m == 0) break;
        for(int i = 0; i < (1 << n); ++i){
            int cnt = 0;
            st[i] = true;
            for(int j = 0; j < n; ++j){
                if(i >> j & 1){
                    if(cnt & 1){st[i] = false; break;}
                }
                else cnt++;
            }
            if(cnt & 1) st[i] = false;
        }
        memset(dp, 0, sizeof(dp));
        dp[0][0] = 1;
        for(int i = 1; i <= m; ++i){
            for(int j = 0; j < (1 << n); ++j){
                for(int k = 0; k < (1 << n); ++k){
                    if((k & j) == 0 && st[j | k]) dp[i][j] += dp[i - 1][k];
                }
            }
        }
        cout << dp[m][0] << '\n';
    }

    return 0;
}
```
