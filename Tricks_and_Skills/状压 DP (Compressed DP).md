# 一、轮廓线 DP

## 1.问题描述
这类题目的核心特征是：通常给定地图，一般是二维网格，且**有一维极其狭窄**（通常 $M \le 12$）。

自顶向下的想，拿到题目可以先考虑状态，状态一般是包含行/列，再根据题目限制拿到其他维的状态定义，先写状态转移方程，一般都是上一行/列转移到下一列，求方案数或者最大放置数量，循环中写带一堆未知量的参数，最后处理再具体处理状态冲突，转移合法状态。

## 2.状态定义的本质（边界跨越）

* 状态压缩的本质，永远只记录状态的更迭，也就是边界的突破。
* 在棋盘中，第 $i$ 行的状态（例如 `j` 的二进制），物理意义不仅代表本行的摆放，更代表了一条分割线，决定这个位置摆放与否或者起到效果。

## 3.预处理 tricks 和状态转移方程

为什么一定要预处理出合法状态数组 `s[]`（比如炮兵阵地）或者 `st[]` 数组？
  
为了防止空间爆炸 MLE。预处理可以把 $1024$ 种理论状态，降维压缩到只有大约$100$ 种 甚至更少真正的合法状态，极大节省空间和常数时间。

## 4.坑点与状态转移限制条件

 **血的教训**：位运算的优先级。判断地形条件时，必须加括号写成`(s[a] & g[i]) == s[a]`，因的优先级高于 `&`，否则会引发全 0 的坍缩。

状态冲突的三层判定逻辑：
  1. **本行合法**（不能有相邻攻击）：例如 `!(i & (i >> 1))`
  2. **上下行互不攻击**（不能捅穿）：例如 `(s[a] & s[b]) == 0`
  3. **不与地形冲突**（不能放在障碍物上）：例如 `(s[a] & g[i]) == s[a]`

### Steve and TNT

矿区可以被抽象为一个 $N \times M$ 的二维网格地图（$1 \le N \le 100, 1 \le M \le 10$）。地图上的每一个方块要么是普通的钻石（可以放置 TNT，用 `.` 表示），要么是“基岩/岩浆”（无法放置 TNT，用 `#` 表示）。

史蒂夫在测试中发现了一个致命的物理特性：为了防止 TNT 爆炸时的动能产生破坏性的叠加共振（导致钻石被直接炸飞），**任意两个被放置的 TNT 之间的曼哈顿距离必须严格大于 2**。

换句话说，如果在一个坐标为 $(x, y)$ 的格子上放置了 TNT，那么所有满足 $|x' - x| + |y' - y| \le 2$ 的合法格子 $(x', y')$ 上都绝对不能再放置 TNT。

作为矿区爆破设计的架构师，史蒂夫希望在遵守上述安全安全距离和地形限制的前提下，尽可能多地部署 TNT。

请你编写一个程序，计算出在这片矿区中，**最多能放置多少个 TNT**？

**【输入格式】**

第一行包含两个正整数 $N$ 和 $M$，分别代表矿区的行数和列数。

接下来 $N$ 行，每行包含 $M$ 个字符（`.` 或 `#`），描绘了下界矿区的地形。

**【输出格式】**

输出一个整数，表示在整个矿区中最多可以放置的 TNT 数量。

**【数据范围与约定】**

- $1 \le N \le 100$
    
- $1 \le M \le 10$




# 二、旅行商（TSP）问题
## 1.问题描述

有 $n$ 个城市，从起点 $0$ 开始游历每一个城市，只访问每个城市一次，最后回到起点，所需要的最短路径是多少？

## 2.状态转移的本质

尚未发现本题多项式时间复杂度的解法。可以考虑穷举全排列，从而获得一个 $O((n−1)!)$ 的做法。然而这通常会 $TLE$，所以需要优化。模拟退火是一个很好的思路，但是正确率不能得到保证。

那么点集如何表示呢？此类问题由于是$NP−hard$ 问题，$n$ 一般很小，所以可以**状态压缩**，设 $S_i​$ 表示 $S$ 的二进制第 $i$ 位，$S_i​ = 0, 1$表示 $i$ 是否在集合内。

**枚举子集的时间复杂度为$O(2^n)$**

不妨设点集位于平面直角坐标系内,即二维坐标，则时间复杂度为 $O(n^2)$， 故总时间复杂度为$O(2^nn^2)$。 

$dp[i][j]$ 表示走到第 $i$ 个点,且走过的二进制状态为 $j$ 时最短距离。

举个例子,可以使用二进制10100110表示已经走过的第 $2, 3, 6, 8$ 个点，第 $i$ 个状态表示**从低位向高位的第 $i$ 位。

## 3.预处理 tricks 和状态转移方程设计

更新 $dp$ 数组时会使用欧式两点距离公式,将 $dp$ 数组初始化为最大值。或者给定整数的 $dis[i][j]$。

总共 $3$ 层循环:分别枚举所有可能的二进制状态 $s$,当前点所在位置 $i$ 与当前点所在位置可达下一个点 $j$ 的位置。**注意，子集枚举一定在前！**

剪枝:判断一下 $i$ 在当前**二进制状态**是否走过 没走过则不需要计算, 在第三层状态下也需判断 $j$ 在当前二进制状态是否走过,没走过不需要计算且 $j$ 与 $i$ 不相同
### 状态转移方程
```cpp
dp[i][S] = min(dp[i][S], dp[j][S & ~(1 << (i - 1))] + dis[i][j])
```

重点来了，这里复杂的位运算表示的物理意义是，不管这一位原本是 0 还是 1，用按位取反 `~` 构造一个“只有这一位是 0，其他全是 1”的掩码，然后用按位与 `&` 砸上去！这一位被死死地钉成 0，其他位保持原样。这样就不需要任何的条件判断。

`ans = min(ans, dp[i][(1 << n) - 1]);` 表示所有地点都已经遍历即可。
